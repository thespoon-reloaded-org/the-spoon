# Short title of the spec

One or two sentences: what changes and for whom.

## Goal

What the outcome is.

## Why

The problem or evidence that justifies the work.

## Scope

- Files, screens or modules expected to change.

## Non-goals

- What this spec deliberately does not do.

## Acceptance criteria (whole spec)

- `pnpm typecheck` and `pnpm lint` pass.
- A checkable statement per outcome.
- Each task below is a separate PR.
